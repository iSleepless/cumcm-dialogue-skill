# 建模与验证：从物理可行到结论可信

## 模型说明要能直接落到程序

按“目标 → 信息 → 变量 → 目标函数 → 约束 → 求解 → 验证 → 含义”解释每问。用户要求公式详细时定义全部符号和单位，解释状态传递与关键约束为何存在。联立约束可用大括号与 `aligned` 排版，但不要把过长表达式塞入一行。

模型复杂度要与数据规模、解释需要、训练时间和可用求解器匹配。自行命名方法时注明其组成，不把自定义名称当作已发表标准方法。

## 按任务选择证据

描述/关联任务先定义分析尺度、变量和缺失口径；趋势/显著性分析注意时序依赖和重复检验，相关网络不要当作因果传输证据。

反演/定位任务先定义观测机制、可行域和可辨识性。检测点数由信息量、误差与退化情形决定，不把“三个点足够”当作对任意几何或传感器任务成立的结论；建议采样点时说明判断标准与停止条件。

生产/种植/资源分配任务从题设核对离散选择、可分割量、轮作、库存与多期约束。“每块地每季只能种一种作物”等约束只有在题面明确或假设经确认时才加入。

## 优化问题

以题设总费用、风险、收益或资源效率为最终目标，避免把预测误差低等同于策略效果好。

写清评价区间。跨日库存或 SOC 与长期目标相关时，逐日独立最优未必等于全年最优。可用滚动时域、终端价值或明确的日循环约束闭合模型；说明选择依据和局限。

初始库存是物理状态，不是可自由获取的电量。数据冷启动与库存初值是不同问题。按题设或已声明假设初始化，之后跨日传递；禁止每天重置满电来制造低费用。

为结果建立费用账本：计划、紧急、上调、下调、弃用或其他成本，含单位与结算时刻。明确减购费用是罚金、退款后净成本还是题设另定义，不能只看到“50%”便自行决定符号。

求解后核对能量/库存守恒、容量与功率边界、充放电互斥、负荷覆盖、初末状态和总费用。报告状态、可行性误差、求解容差和最优间隙等可用证据。

## 预测与决策边界

对每次决策写出信息集合：已观测历史、已公布价格、当时已发布的预报和现有状态。

离线研究可以看全年规律；声称正式在线回测时，每日特征、拟合、误差分位数、专家选择和滚动改约只能使用当时已知数据。不能用年末样本训练模型，再把年初预测称作在线结果。

时间序列用连续时间切分、滚动起点或扩展窗口。调参和模型选择与正式评价分离；首日历史不足采用可解释冷启动策略并单独说明覆盖范围。

必要时比较稳定基线和学习模型。HGB 的“专家”指候选预测器，不等于默认应使用 HGB；代价驱动的模型选择须只评价先前已实现样本。

历史残差分位数用来对冲不对称损失，但分位数应由结算机制推导或历史验证选择。独立报童模型的临界分位数不能直接冒充有储能耦合、多时段约束问题的解析最优值。选取 0.8 是某个模型配置，不是本 skill 的默认答案。

同时报告预测误差与决策指标，例如 MAE/RMSE、总费用、紧急量、未使用电量、服务达标率。区间预测区分标称覆盖率与实际覆盖率。

## 小问独立与更多信息的价值

更换价格或加入预报后保留其余比较口径：评价日期、初值、容量、效率、结算规则。独立小问不得互借新增信息。

在可行集相同且新增信息可以不用的理想优化中，最优目标不应因信息增多而变差；具体拟合或启发式策略仍可能变差。排查信息误用、候选集合、过拟合、价格与账本口径，而非强行写更好的数值。

有改约摩擦时包含“保持原合同”的候选，依据验证成本判断更新预报是否值得交易。不要默认每次发布预报都必须调整。

## 全零与反常结果

紧急量或调整量全为零时依次核对：结果是否成功保存、字段是否正确映射、策略是否真正启用、充放电是否吸收缺口、计划是否过量、弃用是否付费、模型是否误用当天真实值。只在行为与数据一致后解释零值；无法导出结果不能用零填充掩盖。

## 基准、敏感性与结论强度

按论证需要选择无储能、简单预测、原方法、保持合同等基准。完美信息解标为不可实施的成本下界；它不能作为现实策略预测结果。

敏感性围绕不确定假设、参数和信息进行。对样本依赖、时序相关、参数范围和模拟分布作说明。只测过几个情景不要声称全面稳健；统计相关与情景贡献不要写成已证因果。

未经额外试验，不将某个策略在一个数据集中的胜出推广成普适最优。

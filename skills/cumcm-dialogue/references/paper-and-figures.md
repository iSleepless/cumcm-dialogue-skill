# 论文与图表：表达服从结果来源

用户要求完整论文、详细模型与算法过程或应用论文提示词时，补读 [通用论文撰写提示词](paper-writing-prompts.md)，按照分析、建立、求解、结果和解释的主线展开。

## 沿用用户模板

先读取用户 LaTeX 源文件、类文件与版式示例，识别主编译文件和内容入口。要求“只更改内容、模板不变”时沿用章节层级、页眉页脚、字号、表格和附录习惯。

页眉、底部居中页码、无目录、图表独立、附录分问起页等均记录为本项目偏好；不能替用户模板设定全局默认。

写作密度可参考优秀论文的形式结构，模型解释、数据、公式、论证和数字必须来自本工程。

## 每问正文的可读结构

说明研究目的和可用信息，再定义符号与假设，建立目标及约束，讲明求解步骤，展示核验与结果，最后解释它如何回答题目。避免只罗列模型名、公式和图。

题设指定表格逐一列入对应正文或获准的附录，并在正文引用。单位逐列注明；能量为 kWh、费用为元时不能让一条合并单位行涵盖所有列。

长表使用可分页表格与重复表头，避免跨页多行合并导致日期缺失；同一天跨页需清楚续表关系。长公式用分组定义、`aligned` 或拆式，别全局缩小到难读字号。

## 标题、摘要与关键词

在模型和结果版本稳定后改摘要。常用结构为：背景与数据 → 每问的方法、主要结果及其意义 → 总体贡献与适用范围。

标题突出研究对象与真正的核心方法，少用过长模型串。摘要重点模型/算法和关键结果可按用户要求加粗。关键词以对象、主要方法和任务为主，避免同义重复；词数、字数和是否同页依模板与用户偏好确定。

每个数字都能定位到结果文件或表格。百分比与百分点、全年与正式期、费用与电量不可混淆。调整摘要的最优性、稳健性或因果措辞到实际证据强度。

## 作图配置与逐图审核

从用户色系或研究主题建立视觉规范，确认中文/西文字体、最终印刷尺寸、颜色含义和输出格式。保持同一变量的配色语义；浅色填充与可读的边框/文字分别处理。

根据数据与论证选择图型，而非为多样性强行换图：

| 表达目标 | 可选图型与注意点 |
|---|---|
| 时序与预测 | 折线和区间带，密集多线可改热图或独立小图；勿人为平移数据而不说明 |
| 前后提升 | 哑铃/斜率图，匹配同一对象，说明增量和单位 |
| 多模型误差 | 柱图/点图，说明重复实验或不确定性来源 |
| 分布 | 箱线、散点、直方或密度；小样本不要过度平滑 |
| 方案权衡 | Pareto 散点/曲线，标注可行域、选解依据和目标方向 |
| 关联/传输 | 热图或网络，区分统计关系和实际空间距离 |
| 稳健性 | 区间或敏感性排序图，说明采样方法、范围和指标 |

当用户要求逐张审核，生成实际候选图并说明它回答的问题、数据来源、拟替换位置与一两句衔接正文；审核前不修改正式引用。已准许批量替换可直接执行并检查。

科学数据图优先以绘图代码生成，保存矢量 PDF/SVG 和预览 PNG。只把位图放进 PDF 不构成矢量图。示意图或装饰图不充当数值结果图。

## 流程图与渲染检查

流程图若只提供解题思路，节点表示输入、处理、模型、求解和验证，不堆结果数字。图内标题/说明和论文图注的分工按用户要求处理。

节点布局与文字框尺寸一起算：多滞后标签等长文本分行；文字居中且保留内边距；箭头连接节点几何中心或明确端口；虚框包住所有内部节点，给下方路线留间隔；整体裁切后左右留白均衡。

每次重绘或改版面后渲染目标页，检查刻度、边框、箭头、上下标、字体、图例遮挡、颜色对比和页面裁切。编译成功不代表无版式问题。

## 参考文献、附录与支撑文件

按实际引用选择文献，核对作者、题名、年份、期刊/出处与链接；不能为了凑指定篇数或中英文比例生成假文献。

附录标题、位置、全代码或核心代码、分问分页按用户最终约定。完整工程保存于支撑材料；核心片段标明节选或伪代码，不宣称可独立运行。

用同一结果版本维护正文表、附录表、工作簿和图，避免模型更新后只改摘要。

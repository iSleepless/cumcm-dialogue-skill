# AI 数学建模论文撰写提示词（通用整理版）

根据用户提供的论文撰写提示词整理，用于任意研究对象和问题数量。按当前题设、正式结果及论文模板应用，不照搬其他论文的模型、数字或结论。

## 1. 单问写作的五条主要求

1. **分析在模型前。** 先说明目标、信息条件、约束和难点，再解释为何选择该模型。
2. **模型明确。** 定义变量、参数和单位，给出集中可识别的模型关系，避免读者到处拼凑。
3. **公式有解释。** 重要关系式、目标和约束说明现实含义、来源与成立条件。
4. **建立与求解分开。** 建立部分说明数学描述；求解部分说明如何估计、训练、迭代或优化。
5. **过程与结果都完整。** 代码、终值或一幅图都不能替代必要的算法步骤和结果说明。

每问、每个小问和题设指定输出均要有对应结果。即使结果为零、差异不明显或与直觉一致，也明确说明计算口径、核验和含义。

## 2. 输入与写作配置

写作前读取题意约定、正式模型、数据处理记录、算法配置、结果表、图件及其来源。若求解尚未完成，可以写方法草稿，结果位置标为待计算，不填经验数值。

沿用用户模板的章节结构、字号、页眉页脚、公式和表格习惯。以下属于可选配置，而不是通用固定要求：摘要篇幅与加粗、关键词数量、是否有目录、附录范围、逐问分页、中英文文献比例及色系。

参考优秀论文的写作密度和层次，内容依据本工程。用户已明确的配置优先于本指南中的默认结构。

## 3. 建议全文结构

```text
标题、摘要、关键词
问题重述与分析
模型假设、符号与数据处理
第 1 问 … 第 n 问：分析、建立、求解、结果、解释
必要的模型验证、敏感性与评价
结论、适用范围与局限
参考文献、附录和适用规则要求的 AI 使用声明/报告
```

标题、摘要与关键词在正式结果稳定后定稿。AI 声明位置和附录位置按用户模板及适用规则确定，不沿用未经核对的历史规定。

## 4. 每问可复用的详细结构

```markdown
## 第 k 问：研究主题

### 问题分析与建模思路

说明研究目的、输入、输出、决策/观测条件、约束与难点。
说明方法选择理由，以及需区分的原题条件和新增假设。

### 参数、变量与现实意义

| 名称 | 符号 | 类型 | 现实含义 | 单位/取值 |
|---|---|---|---|---|

### 模型建立

先定义核心关系，再写目标或估计准则及约束。
逐项解释关键公式及成立条件，说明模型类型和适用范围。

### 求解方法

按算法输入、预处理、初始化、主要步骤、停止/选模规则和输出展开。
给出实际工具、关键参数依据、数据划分与复现入口。

### 求解结果

列出主要结果、必要中间参数、评价指标及题设指定日期表。
表格逐列标明单位，引用正式结果来源；零值与失败状态如实说明。

### 结果分析与验证

解释结果怎样回答原题，与必要基准作同口径比较。
给出实际执行的约束核验、预测验证或统计诊断。
提出证据支持的建议，并说明适用条件与局限。
```

Markdown 每个标题、段落和列表之间保持合理空行；转为 LaTeX 时用模板的段落与小节结构，不用手工换行符堆空白。

## 5. 各部分写作重点

### 分析与建立

参数要有现实解释，公式要有来源。不能先决定某个模型名字，再把题意强行凑进去；同样不能用“创新模型”代替完整变量和关系式。

约束较多时可用大括号和对齐结构集中展示，长表达式拆开定义。统计模型说明响应、解释变量与误差/估计假定；优化模型说明目标、变量域及关键约束。

### 求解

描述实际执行的算法步骤、参数、初始化、结束条件和工具。预测说明训练/验证/评价区间，优化说明求解状态和适用的最优性证据；不要把试过但未采用的方法写成正式方法。

中间结果选择能支持复核和理解的内容，不把所有日志塞进论文，也不省略必要参数与过程。

### 结果与解释

主要结果默认放在相应正文，满足题设所有小问和论文表格要求。若用户要求附录集中列示或长表需分页，正文保留主要数值结果、必要解释和关键结论并清楚引用。外部 Excel 和附录代码不替代正文中的求解说明。

结果表包括问题/方案、数值、单位、评价口径与必要备注。各列单位独立，百分比与百分点、总量与均值区分。图前说明比较对象和目的，图后说明观察结果及其含义。

“最优”“显著”“稳健”“因果”“提升”都与实际证据对应；没有完成验证时保留未核验状态。

### 摘要与关键词

按“背景与数据—各问方法和关键量化结果—总体贡献与范围”组织，问题段数依实际题目。只引用当前正式结果；用户要求时对主模型、算法和核心数值局部加粗。

关键词覆盖对象、主方法和任务，避免同义词重复。标题、摘要和关键词能概括正文，篇幅及同页要求按模板配置。

## 6. 可直接复制的总提示词

```text
请作为数学建模论文写作助手，根据本工程的题意约定、正式模型、
数据预处理记录、算法配置和实际结果撰写论文，沿用我提供的模板。

每问按“问题分析—模型建立—求解方法—求解结果—结果分析”推进：
先分析目标、信息和难点；定义参数变量及单位；明确核心公式、目标和约束，
解释关键关系的实际含义；把求解写成可复现步骤，说明实际工具和参数依据；
完整展示主要和必要中间结果，满足题目指定的日期、表格及文件要求；
最后解释数学结果怎样回答原题，给出验证、建议和局限。

模型建立与求解分别说明；程序不能代替求解过程和结果。
结果数值以正式产物为准，未计算的地方标注待计算。
核心结果放在对应正文；附录与分页遵循本项目已确认的安排。
摘要最后依据正文和结果文件定稿，图表前后补充必要的衔接与分析。
参考论文只学习结构与表达，不移用其具体结论。
```

## 7. 分阶段短提示词

- **先分析：**“先说明第 k 问的目的、条件、难点和选模理由，暂不撰写最终结果。”
- **补模型：**“定义所有重要符号与单位，集中给出数学模型，逐项解释目标与关键约束。”
- **补求解：**“把实际执行的方法写成算法步骤，解释初始化、参数依据、迭代/选模与输出。”
- **补结果：**“依据正式结果补齐各小问、必要中间量和指定日期表；不得以程序、附录代码或全量表代替正文必需结果与解释，完整长表可按已确认安排放附录。”
- **改摘要：**“按照背景、各问方法与结果、总体结论组织摘要，数值与正式版本一致。”
- **终稿检查：**“检查题意、模型、求解、结果、图表、引用和格式之间的一致性，列出证据和缺口。”

## 8. 质量检查

- [ ] 分析先于模型，目标与方法选择有解释。
- [ ] 模型明确，符号、单位、公式与现实含义一致。
- [ ] 建模与求解区分，参数和算法过程可复现。
- [ ] 各问、小问、主要结果和必要中间结果完整。
- [ ] 图表、摘要、正文和交付文件来自同一结果版本。
- [ ] 结果分析回应题目，结论强度与验证相符。
- [ ] 参考文献、版式、附录和 AI 声明符合实际配置及规则。

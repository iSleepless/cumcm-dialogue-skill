# 对话式国赛数学建模 Skill

面向全国大学生数学建模竞赛（CUMCM）的可安装 AI skill，把“先读题、再讨论、逐问运行、结果核验、论文与图表、官方填表和支撑材料”组织成持续可恢复的工作流。

来自多次空气质量和微网任务的人机协作经验。本仓库只包含新整理的通用方法、匿名交互案例与辅助脚本，不包含赛题原文、原始数据、参赛论文、个人信息或在线项目凭据。

## 能帮助你完成什么

- 逐问解释题意、单位、时间索引、可用信息和必须交付的表格。
- 防止预测泄漏、初始库存重置、小问信息互借、成本口径混用。
- 以可运行代码与结果文件支撑模型、摘要、图表和指定日期表。
- 沿用论文模板，处理长公式/长表、独立科研图与逐图审核。
- 核对官方 Excel 母版，区分结构一致与结果覆盖完整。
- 区分本地完成、上传、在线保存、编译和刷新后持久化。
- 根据真实交互编写 AI 使用说明，整理可复现支撑材料。

不预设必须使用 HGB、MILP、固定 0.8 分位数或某种配色。skill 是工作方法，不是某道赛题的现成答案，也不保证比赛获奖或更低成本。

## 安装

仓库中的技能目录为 `skills/cumcm-dialogue/`。把这个完整文件夹放入你的客户端支持的 skills 目录；支持 `SKILL.md` 的客户端可读取入口，`agents/openai.yaml` 是可选 Codex 界面元数据。

Codex 用户也可以把仓库链接发给助手：

```text
请使用 skill-installer 从这个 GitHub 仓库安装 skills/cumcm-dialogue。
```

安装完成后，可调用 `$cumcm-dialogue`。在支持自动技能选择的客户端中，也可直接描述国赛建模需求。

## 典型用法

```text
使用 $cumcm-dialogue 读取我提供的赛题和附件。
先逐问解释目标、信息边界、约束和输出要求，暂不求解。
```

```text
继续问题二。每天零点只能知道历史负载与光伏。
先核对初始储能和回测边界，再运行可解释基线与主方法，评价总购电费用。
```

```text
请按我的 LaTeX 模板整理模型与结果，摘要数值以当前结果文件为准。
新图先逐张给我审核，官方 Excel 只填指定区域，保留原题头。
```

## 目录

```text
skills/cumcm-dialogue/
  SKILL.md
  agents/openai.yaml
  references/          # 按阶段加载，不一次性塞入所有资料
  assets/              # 项目状态与单问任务约定模板
  scripts/             # 只读官方 XLSX 结构审计工具
tests/                 # 合成工作簿验证，不含用户比赛文件
```

入口和参考以中文为主，脚本支持 Windows/macOS/Linux。执行工作簿审计需 Python 3.10+ 和 `openpyxl`；其他阶段不要求安装此依赖。

## 本地验证

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

示例案例是匿名的交互经验，不是经独立验证的竞赛结果。使用时应核对实际题设、当年赛事规则和团队的真实 AI 使用情况。
